## 🚀 Как запустить проект

1. **Клонируйте репозиторий**:

   ```bash
   git clone https://github.com/javoxirone/text-analyzer.git
   cd text-analyzer
   ```

2. **Создайте виртуальное окружение (рекомендуется)**:

   ```bash
   python -m venv env
   source env/bin/activate        # для Linux/Mac
   env\Scripts\activate           # для Windows
   ```

3. **Установите зависимости**:

   ```bash
   pip install -r requirements.txt
   ```

4. **Примените миграции базы данных**:

   ```bash
   python manage.py migrate
   ```

5. **Создайте суперпользователя**:

   Для доступа к административной панели (админке) создайте суперпользователя с помощью команды:

   ```bash
   python manage.py createsuperuser
   ```

   После запуска команды введите:

   - имя пользователя (например: `admin`)
   - адрес электронной почты (можно оставить пустым)
   - пароль (дважды)

   Пример:

   ```
   Username: admin
   Email address: 
   Password: ********
   Password (again): ********
   Superuser created successfully.
   ```

6. **Запустите сервер разработки**:

   ```bash
   python manage.py runserver
   ```

7. **Откройте в браузере**:

   - Главная страница: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
   - Админка: [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/)

---

## ⚙️ Возможности админ-панели

В административной панели можно выполнять **CRUD-операции над загруженными текстовыми файлами**:

- Просматривать список загруженных документов
- Удалять или редактировать записи
- Контролировать результаты TF-IDF-анализа
- При необходимости вручную добавлять документы

Для доступа к админке используйте логин и пароль суперпользователя, созданного на шаге 5.
